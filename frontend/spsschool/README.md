Fluxo mental:

Container → moldura e estilo visual.

Column ou Row → estrutura de layout.

Children → widgets de conteúdo.

Cada filho → aplica seus próprios estilos (TextStyle, InputDecoration, etc.).

Pense como “camadas aninhadas”:
COntainer > Estilo > child > Column > children > Estilos > COmponente de texto ou seleção ou o que for do form
Container → Layout (Column) → Widgets (Text, TextField, Button).
